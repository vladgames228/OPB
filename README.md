# olx-parser-bot

Телеграм-бот, отслеживающий сохранённые поиски на olx.uz и присылающий новые
объявления: фото группой, заголовок и цена сверху, текст — тело, комментарий
(если есть), номер и ссылка на источник внизу. Под каждым объявлением —
кнопки ⭐ избранное, 👎 не интересно (и его переподачи тоже), 💬 комментарий.

## Запуск

1. Скопируй `.env.example` в `.env`, впиши `BOT_TOKEN` (от @BotFather) и свой
   `ALLOWED_USER_IDS` (узнать id можно у @userinfobot).
2. `docker compose up -d --build`
3. В телеграме:
   - `/group_add Квартиры` → бот вернёт id группы, например 1
   - `/add 1 https://www.olx.uz/.../q-xxxxxxx https://www.olx.uz/.../q-yyyyyyy`
     — можно сразу несколько ссылок через пробел

## Команды

- `/group_add <название>` — создать группу поисков
- `/group_list` — список групп
- `/group_remove <id группы>` — удалить группу вместе со всеми её поисками
- `/add <id группы> <ссылка1> [ссылка2] ...` — добавить один или несколько
  поисков olx.uz в группу
- `/list` — активные поиски по группам; ссылка сокращается до текста между
  `q-` и следующим `/` или `?` (сам поисковый запрос)
- `/remove <id поиска>` — удалить один поиск
- `/check` — проверить все поиски прямо сейчас, не дожидаясь таймера
- `/latest <id поиска>` — прислать самое свежее объявление по поиску, не
  помечая его увиденным — чтобы убедиться что парсер жив
- `/favorites` — список сохранённого в избранном

Список команд также зарегистрирован в самом Telegram (кнопка "Меню" рядом
с полем ввода).

## Группировка и дедупликация

Если одно и то же объявление подходит под несколько поисков внутри одной
группы, бот пришлёт его один раз (статус "увидено" хранится на уровне
группы, а не отдельного поиска).

При добавлении поиска (`/add`) бот берёт текущие объявления на странице как
базовую линию и не присылает их — только то, что появится после.

## Избранное / не интересно / комментарий

Каждое присланное объявление получает кнопки:
- **⭐ Избранное** — сохраняет в `/favorites` и **удаляет пост целиком из
  чата** (фото + панель с кнопками), чтобы не копился хлам — объявление
  уже сохранено, смотреть его потом через `/favorites`. Там у каждой
  записи своя кнопка **🗑 Удалить из избранного**.
- **👎 Не интересно** — объявление больше не пришлют, и если автор
  переопубликует его (новое id на OLX, тот же текст/цена/телефон), бот
  тоже его не пришлёт.
- **💬 Комментарий** — бот попросит прислать текст, сохранит его. Если это
  же объявление попадётся снова (в том числе после переподачи), комментарий
  появится в сообщении. Нажатие на кнопку ещё раз позволяет заменить
  комментарий на новый.

Технически "то же самое объявление" при переподаче определяется по
отпечатку (нормализованный заголовок + телефон/имя продавца + цена), а не
по id — id на OLX при переподаче меняется. Это эвристика: разные продавцы
с очень похожим заголовком и ценой (например одинаковый шаблон объявления)
теоретически могут случайно попасть под один отпечаток. Для личного
использования этого достаточно.

## Скорость запросов к olx.uz

Каждый HTTP-запрос к olx.uz (что страница поиска, что страница объявления)
делается со случайной паузой 3–5 секунд перед ним — это встроено в саму
функцию запроса, так что все команды (`/add`, `/check`, обычный опрос по
таймеру) автоматически не долбят сайт чаще этого. При добавлении сразу
нескольких ссылок в `/add` или при большом количестве новых объявлений это
означает, что ответ может занять заметное время — это ожидаемо.
